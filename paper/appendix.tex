participant expansion, pathway co-membership, regulator-chain, and co-complex

\section{DREAM4 Fallback}

The intended DREAM4 Predictive Signalling Network Modeling project is available
as Synapse metadata at \texttt{syn2825304}, but file listing/download required
authenticated Synapse access in this environment. The Step 7 tripwire therefore
fired. The fallback dataset is a synthetic linear non-Gaussian SCM derived from
the DREAM4 HepG2 phosphoprotein panel and Reactome/literature-compatible
signalling structure.
